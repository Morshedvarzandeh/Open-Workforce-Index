# Announcement draft — publish after verifying the demo URL

I built Open Workforce Index because choosing an AI model for every task can
become a job of its own.

OWI compares estimated costs, checks supported result requirements, and uses
your feedback to inform later choices. It runs locally with your configured
model commands. Subscription allowance and API estimates are shown separately.

There is now an install-free browser example, plus a connected GUI for real
tasks. Agents can also acquire bounded working reminders after repeated check
failures, with trial versions and rollback.

This is an early open-source project. Starting ability estimates are assumptions;
I am not claiming benchmarked savings or general self-improvement yet.

I am looking for 10 developers who already use multiple AI models to try one
real task and tell me where the setup or recommendation fails them.

Code, walkthrough, and setup:
https://github.com/Morshedvarzandeh/Open-Workforce-Index
