# Roadmap

The roadmap is ordered by evidence, not UI surface area.

## v0.1 — decision kernel

- Exact, immutable worker identity
- Public/private SQLite trust boundary
- Beta evidence updates and conservative quality bounds
- Hard eligibility filters and expected accepted-result cost
- Auditable quote, exclusion explanations, and Pareto frontier
- SKOS/PROV-O ontology plus SHACL contract
- CLI examples and privacy regression tests

## v0.2 — reproducible index and accountable usage

- Versioned JSON source schema and import adapters
- Domain/task applicability metadata and an AA-Omniscience adapter that keeps
  factual recall, calibrated abstention, hallucination, protocol, and cost
  separate from artifact and tool capabilities
- Model-release and provider-offering lifecycle gates
- Historical price/quota schedules
- Hash-addressed, canonicalized and signed public snapshots
- Reproducibility manifest and source-license checks
- Scheduled discovery with human-reviewed promotion
- Versioned application adapters and typed artifact/acceptance manifests,
  beginning with repository code and mechanical CAD
- Versioned advisor/recommendation protocol and a read-only local service that
  separates ready, setup-required, and excluded workers
- Pre-run quote/approval, bounded-lease, role-event, circuit-breaker, and
  actual-versus-estimated receipt schemas before browser execution is enabled
- Private Git project, repository, worktree, and commit-context registry
- Append-only usage events linked to tasks, attempts, exact workers, and tools
- Atomic project allocations that reconcile exactly to every source total
- Generic JSON usage import plus one end-to-end provider or harness adapter
- Project and portfolio reports by model, task, retry, verification, tool, and
  subscription attribution
- Full decision audit plus a baseline frozen before execution
- Savings output labeled `counterfactual_estimate`, with coverage, exclusions,
  uncertainty, and no claim of observed cash savings
- Reconciliation CLI and regression fixtures for corrections, refunds,
  multi-currency usage, retries, checkers, and subscription reclassification
- Versioned environmental profiles with functional units, lifecycle and
  measurement boundaries, source provenance, uncertainty, and factor snapshots
- Project-report coverage for energy, separate location/market CO2e, separate
  water withdrawal/consumption, structured unknowns, and counterfactual avoided
  impacts that never net against the actual inventory

## v0.3 — personal workforce

- Native provider/API and official coding-agent adapters
- Repository context packs, worktree isolation, and permission leases
- Deterministic test/lint/build verification
- Cheap-first escalation and independent maker/checker policies
- Multi-dimensional budgets for API cash, subscriptions, local compute, and time
- Local dashboard with plan preview and assignment override
- Recommendation-first Chrome Manifest V3 side panel and explicit selected-text
  context-menu action, followed by Edge and Brave compatibility packages
- Least-privilege browser permissions, Native Messaging boundary, consented page
  fields, and opt-in versioned application adapters
- `recommend`, `run`, and `project` client modes, with direct execution disabled
  until the user approves an exact worker plan and maximum-spend lease
- Provider-site copy/deep-link/manual-import flow without cookie, OAuth, session,
  or result scraping; official APIs use credentials held by the local service
- Live planner/maker/checker/retry/tool timelines, streamed API output or opaque
  artifact references, and reconciled receipts by model and Git project
- Hard daily, weekly, task, project, and provider caps, with no automatic credit
  purchase, top-up, subscription upgrade, or gamified credit interface
- Separate consent for raw prompt/output display, local persistence, redaction,
  retention, and export

## v0.4 — learned allocation

- Repository/task-class calibration and drift detection
- Low-risk, capped Thompson exploration
- Champion/challenger evaluation from opted-in tasks
- Whole-project DAG allocation under budget and deadline
- Integrations with existing agent control planes

## Not before evidence supports it

- A neural router trained on private telemetry
- An open marketplace or multi-tenant hosted execution service
- Full OWL-DL reasoning in the critical allocation path
- Anonymous upload of prompts, repositories, or private outcomes
